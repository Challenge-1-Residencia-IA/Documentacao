# Público-alvo

O público inicial deve ser definido com base em pesquisas e testes com usuários. Ainda assim, alguns perfis podem ser considerados hipóteses iniciais para orientar o design do produto.

## Usuários que recebem informações frequentemente pelo Telegram

São pessoas que recebem mensagens encaminhadas, links e conteúdos de familiares, amigos, grupos e comunidades.

## Usuários que têm dúvidas sobre informações, mas não sabem como verificar

Esse grupo não necessariamente acredita em desinformação. O problema pode ser simplesmente não saber onde pesquisar ou como avaliar uma fonte.

## Usuários que fazem verificações para outras pessoas

Existe um perfil particularmente interessante: a pessoa que frequentemente recebe mensagens como "isso é verdade?". Esses usuários podem usar a ferramenta como um primeiro ponto de investigação antes de responder a quem perguntou.
