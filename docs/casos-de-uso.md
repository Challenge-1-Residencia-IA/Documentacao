# Casos de uso

## UC01. Analisar mensagem

Usuário envia texto. O sistema identifica afirmações e inicia a investigação.

## UC02. Analisar link

Usuário envia uma URL. O sistema acessa o conteúdo disponível, identifica as principais afirmações e realiza a análise.

## UC03. Solicitar explicação

Usuário pergunta por que uma determinada avaliação foi apresentada. O sistema explica as evidências e fontes utilizadas.

## UC04. Consultar fonte

Usuário solicita informações sobre uma fonte específica. O sistema explica sua relação com a afirmação analisada.

## UC05. Fornecer nova evidência

Usuário envia uma nova fonte. O sistema compara a nova informação com as evidências existentes.

## UC06. Questionar a análise

Usuário discorda da avaliação. O sistema não deve simplesmente insistir na resposta anterior: deve investigar o argumento apresentado.

## UC07. Informação sem evidências

Usuário envia uma afirmação para a qual não existem dados suficientes. O sistema informa a insuficiência de evidências.

## UC08. Fontes divergentes

Fontes confiáveis apresentam resultados diferentes. O sistema apresenta a divergência e explica possíveis motivos.

## UC09. Informação fora de contexto

A afirmação tem origem verdadeira, mas é apresentada de forma enganosa. O sistema mostra o contexto original.

## UC10. Informação desatualizada

A informação já foi verdadeira, mas não representa a situação atual. O sistema destaca a diferença temporal.
